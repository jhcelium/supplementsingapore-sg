# 小红书 RSS 内容监控技能（SKILL 01）

从用户提供的 Inoreader OPML 文件或 RSS 链接中，抓取并筛选出最适合改编为小红书内容的全球热门健康文章。

## 用户输入格式

以下任意一种：
- OPML 文件路径（如 `~/Downloads/inoreader-export.opml`）
- 单个或多个 RSS 订阅 URL
- 直接粘贴文章链接（批量处理）

## 工作流程

创建任务清单，按以下步骤执行：

### 第1步：解析 OPML 文件

读取 OPML 文件，提取所有 RSS 订阅源：

```bash
# 读取 OPML 文件
cat <opml文件路径>
```

从 OPML XML 中提取每个 `<outline>` 标签的：
- `title`：订阅源名称
- `xmlUrl`：RSS feed URL
- `htmlUrl`：网站主页

将所有订阅源按分类整理成列表。

### 第2步：抓取 RSS Feed 内容

对每个 RSS feed URL，使用 WebFetch 工具获取最新文章列表：

**目标内容类型（优先抓取）：**
- 健康与营养（Health & Nutrition）
- 膳食补充剂（Dietary Supplements）
- 抗衰老与长寿（Anti-aging / Longevity）
- 运动与恢复（Sports & Recovery）
- 肠道健康（Gut Health）
- 心脑血管健康（Cardiovascular Health）

**重点监控网站示例：**
- Examine.com（补充剂科学研究）
- Healthline.com（大众健康科普）
- WebMD.com（医疗健康资讯）
- NutritionFacts.org（营养科学）
- PubMed / ScienceDaily（学术简报）
- Reddit r/Supplements（用户讨论热帖）

### 第3步：筛选爆款文章

**筛选标准（满足3条以上优先推荐）：**

内容相关性：
- [ ] 与保健品/营养补充剂直接相关
- [ ] 与新加坡目标用户痛点吻合（免疫力、美白、关节、精力）
- [ ] 有具体数据、研究结论或实用建议

改编潜力：
- [ ] 有明确的"结论"或"观点"（适合提炼成小红书核心卖点）
- [ ] 信息量适中（不过于学术，也不过于浅显）
- [ ] 无严重医疗声明风险

时效性：
- [ ] 发布时间在近30天内（优先）
- [ ] 或属于常青内容（Evergreen，持续有搜索需求）

### 第5步：生成本周内容计划建议

根据筛选结果，建议本周可发布的内容组合：

```
本周小红书内容建议（X篇）
━━━━━━━━━━━━━━━━━━━━━━━━
周X：[文章编号] → [建议改编角度]
周X：[文章编号] → [建议改编角度]
...
```

## 注意事项

- 使用 WebFetch 工具抓取 RSS/文章内容
- 如某 RSS URL 无法访问，跳过并记录，继续处理其他源
- 筛选时优先考虑"容易改编"而非"内容最专业"
- 保留原文链接以便后续改编时参考
- 不得直接复制原文，仅用于内容灵感和素材来源
