# 小红书发布流水线技能（SKILL 04）

整合内容监控（xiaohongshu-rss-monitor）和文章改编（xiaohongshu-article-adapter）的完整工作流，从内容发现到发布就绪，一键完成本周/本批次的小红书内容生产。

## 用户输入格式

以下任意一种：
- OPML 文件路径（触发完整流水线）
- 文章 URL 列表（跳过RSS监控，直接改编）
- 指定数量："本周需要 X 篇小红书内容"

## 工作流程

创建完整任务清单，按顺序执行：

---

### 阶段一：内容发现（来自 xiaohongshu-rss-monitor）

#### 步骤 1.1：加载订阅源

如提供 OPML 文件：
```bash
cat <opml文件路径>
```
解析所有 RSS 订阅 URL，整理成列表。

如直接提供文章 URL，跳至阶段二。

#### 步骤 1.2：抓取最新文章

对每个 RSS 源，使用 WebFetch 获取最新文章列表（最近30天）。
记录每篇文章的：标题、链接、发布日期、来源网站。

#### 步骤 1.3：初步筛选

按相关性快速筛选，保留与以下话题相关的文章：
- 膳食补充剂（vitamins, supplements, probiotics, omega-3...）
- 营养与健康（nutrition, gut health, immunity, anti-aging...）
- 健康趋势（wellness trends, longevity, biohacking...）

剔除：纯医疗新闻、广告软文、与保健品无关的内容。

**输出：候选文章清单（10-20篇）**

---

### 阶段二：内容评估与排序

#### 步骤 2.1：评分矩阵

对每篇候选文章打分（1-5分）：

| 维度 | 评分标准 |
|------|---------|
| **小红书适配度** | 有明确观点、有数字/故事、结论清晰 |
| **新加坡相关性** | 与本地健康趋势、气候、饮食习惯相关 |
| **改编难度** | 信息量适中，非过度学术，改编成本低 |
| **话题热度** | 是否为当前流行话题或常青话题 |

#### 步骤 2.2：选定本批次文章

根据用户需求（如"本周3篇"），从评分最高的文章中选取。

**选取原则：**
- 话题多样化（不重复相同品类）
- 内容类型均衡（科普型 + 避坑型 + 测评型）
- 时效性优先（新研究 > 旧内容）

---

### 阶段三：批量改编

对每篇选定文章，执行以下改编流程（参考 xiaohongshu-article-adapter 技能）：

#### 步骤 3.X（每篇重复）：

**3.X.1 抓取原文**
使用 WebFetch 读取文章完整内容。

**3.X.2 提炼要点**
提取 3-5 个核心要点，中文口语化表达。

**3.X.3 生成笔记**
生成完整小红书笔记：
- 3 个备选标题
- 完整正文（600-1000字，摘要提炼风格）
- 15-20 个分层话题标签
- 配图建议

**3.X.4 合规检查**
逐项确认合规要求通过。

---

### 阶段四：发布队列生成

#### 步骤 4.1：排期建议

根据改编完成的笔记数量，生成发布排期：

**发布时间建议（小红书高活跃时段）：**
- 工作日：12:00-13:00（午休）、19:00-21:00（下班后）
- 周末：10:00-11:00、20:00-21:00
- 新加坡时区（SGT，UTC+8）

**发布间隔：**
- 建议至少间隔1天（避免账号被限流）
- 同一话题笔记间隔至少3天

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[日期] [建议时间] → 笔记[编号]：[标题]

```

#### 步骤 4.2：每篇发布清单

为每篇笔记生成独立的发布 checklist：

```

- [ ] 正文已定稿
- [ ] 话题标签已复制
- [ ] 配图已准备（X张）
- [ ] 封面图文字已添加

发布前检查：
- [ ] 无医疗声明
- [ ] 无绝对化表述
- [ ] 数据来源已核实
- [ ] "内容仅供参考"已添加（如适用）

发布后操作：
- [ ] 发布成功截图
- [ ] 记录发布时间和初始数据
- [ ] 24小时后检查数据（点赞/收藏/评论）
```

## 与其他技能配合使用

| 场景 | 建议使用 |
|------|---------|
| 只想抓取内容，不改编 | xiaohongshu-rss-monitor |
| 已有文章链接，只需改编 | xiaohongshu-article-adapter |
| 从头到尾全流程 | **xiaohongshu-publish-pipeline（本技能）** |

## 注意事项

- 每次运行建议批量处理 3-5 篇（避免内容质量下降）
- OPML 文件如订阅源过多（50+），建议先用 xiaohongshu-rss-monitor 筛选
- 所有内容需人工最终审核后再发布
- 改编内容注明"整理自外网资讯"，保持透明度
