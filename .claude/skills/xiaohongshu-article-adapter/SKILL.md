# 小红书文章改编技能（SKILL 03）

将来自 Inoreader 或其他来源的英文健康文章，提炼核心要点并改编为适合小红书发布的中文图文笔记。

## 用户输入格式

以下任意一种：
- 文章 URL（Claude 将自动抓取内容）
- 直接粘贴的文章原文（英文）
- 来自 xiaohongshu-rss-monitor 技能的文章编号（配合使用）

## 工作流程

创建任务清单，按以下步骤执行：

### 第1步：抓取并解读原文

如用户提供 URL，使用 WebFetch 工具读取文章全文。

提取以下信息：
- **核心论点**：文章主要想说什么？（1句话概括）
- **关键数据**：有哪些数字、研究结论、百分比？
- **实用建议**：文章给出了哪些行动建议？
- **目标受众**：这篇文章原本写给谁看的？
- **潜在风险点**：是否有不适合直接翻译的医疗声明？

### 第2步：确定小红书改编角度

根据原文内容，选择最适合的小红书内容切入角度：

| 原文类型 | 推荐小红书角度 |
|---------|--------------|
| 研究报道 | "最新研究发现：XX原来这么重要" |
| 实用指南 | "关于XX，这X点你必须知道" |
| 误区纠正 | "很多人吃XX都吃错了，这才是正确方式" |
| 产品对比 | "XX保健品选购完全指南" |
| 个人体验 | "坚持吃了X个月的真实变化" |
| 专家观点 | "营养师说的，关于XX这件事" |

### 第3步：提炼核心要点（3-5个）

从原文提取 3-5 个核心要点，每个要点：
- 用中文口语化表达（非直译）
- 保留关键数据/研究依据
- 去除过于专业或医疗的表述
- 确保每个要点独立成立，可以单独理解

**提炼原则（摘要提炼风格）：**
- ✅ 保留：核心结论、实用数字、行动建议
- ✅ 保留：对比信息（如"A比B多含X%的Y"）
- ❌ 删除：过度技术细节、长篇学术讨论
- ❌ 删除：绝对化医疗声明（"治愈""处方"）
- ❌ 删除：不适合新加坡市场的内容（美国保险、FDA处方等）

### 第4步：撰写小红书标题（3个备选）

**标题公式：**
- 疑问型：`[痛点/疑问]？这篇说清楚了`
- 数字型：`X个关于[话题]的真相，第X个很多人不知道`
- 反转型：`以为[常见误解]，其实[正确答案]`

**标题要求：**
- 15-20字以内
- 前5字含核心关键词（小红书SEO关键）
- 口语化，有点击欲望
- 不夸大，不造假，不违反平台规定

### 第5步：撰写正文

**结构模板（摘要提炼风格，600-1000字）：**

```
【开场引入 - 80-120字】
用一个贴近生活的场景或问题开场，引发共鸣。
不直接说"翻译自XX文章"，而是用自然的第三人称或第一人称。

例："最近在刷外网健康资讯，看到一篇很有意思的研究..."
或："很多人问我XX问题，今天找了几篇专业文章，给大家整理一下..."

【核心要点 - 300-500字】
用简洁的方式呈现3-5个要点：

💡 要点1：[标题]
[2-3句话说明，含数据支撑]

💡 要点2：[标题]
[2-3句话说明]

（以此类推...）

【新加坡本土化信息 - 80-150字】（如适用）
- 本地购买建议（Guardian、Watsons、iHerb SG、Lazada SG）
- 本地价格区间（SGD）
- 本地气候/饮食习惯的相关性

【结尾互动 - 50-80字】
引导读者互动或行动：
"你们平时有在补充XX吗？"
"如果这篇对你有帮助，记得收藏⭐"
"想了解更多的，评论区告诉我👇"
```

**格式要求：**
- 每段不超过3行（手机阅读节奏）
- 适量使用 emoji（💡✅⚡🌿💊）增加可读性
- 重要信息加【】标注
- 数字和专有名词保持醒目

### 第6步：生成话题标签（15-20个）

**分层标签策略：**

账号固定标签（每篇必带，5个）：
`#新加坡保健品` `#新加坡养生` `#保健品推荐` `#健康干货` `#SG生活`

内容话题标签（根据文章内容选5-8个）：
- 从文章关键词中提取相关中文话题
- 参考：`#胶原蛋白` `#益生菌` `#维生素D` `#Omega3` `#鱼油` `#免疫力` `#肠道健康` `#抗衰老` `#关节保护` `#补充剂`

人群标签（精准定向，3-5个）：
`#新加坡妈妈` `#上班族养生` `#30+保养` `#健身打卡` `#学生党`

### 第7步：配图建议

提供 3-5 张配图的内容方向：
- 封面图：与话题相关的产品或场景照（建议尺寸 3:4）
- 要点图：将核心3-5个要点做成简洁的信息图
- 氛围图：健康生活方式场景（早晨routine、健身、煮食）

### 第8步：合规检查

发布前检查清单：
- [ ] 无绝对化健康声明（不出现"治愈""治疗""处方"）
- [ ] 无虚假数据（所有数字来自原文，已注明）
- [ ] 无抄袭（已改写，非直译）
- [ ] 符合小红书社区规范
- [ ] 标注"内容仅供参考，非医疗建议"（如涉及健康功效）
