🔄流水线阶段
阶段一：内容发现
1.1 加载 OPML，解析所有 RSS 订阅 URL
1.2 WebFetch 抓取近30天最新文章（标题/链接/日期/来源）
1.3 初步筛选：保留补充剂/营养/健康趋势，剔除医疗广告
阶段二：内容评估与排序
2.1 四维评分：小红书适配度 / 新加坡相关性 / 改编难度 / 话题热度（各1-5分）
2.2 选定批次文章：话题多样化 + 类型均衡 + 时效性优先
阶段三：批量改编
3.X.1 抓取每篇原文完整内容
3.X.2 提炼3-5个核心要点（口语化）
3.X.3 生成笔记：3个备选标题 + 完整正文 + 15-20标签 + 配图建议
3.X.4 逐篇合规检查
阶段四：发布队列生成
4.1 按高活跃时段自动排期，生成完整发布日历
4.2 为每篇生成独立发布 checklist（内容准备/发布前/发布后）
阶段五：完整报告输出
5.1 汇总所有笔记内容 + 发布排期总览 + 每篇清单
